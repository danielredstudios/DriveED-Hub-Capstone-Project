DRIVEED HUB - FIX VERIFICATION AND CLIENT DEMO GUIDE
======================================================




1. START THE APPLICATION
------------------------
Open PowerShell in the project folder and run:

    docker compose up -d --build
    docker compose exec app php artisan migrate

Open the login page:

    http://localhost:8004/drived-hub/login

If the application is not available, check:

    docker compose ps
    docker compose logs --tail=100 app

PREPARE FULL BUG-DEMO DATA
--------------------------
After a clean database reset, seed the transactional records required by the
dashboard, booking, cancellation, instructor roster, and TDC batch tests:

    docker compose exec app php scratch/seed_bug_demo_data.php

This creates an approved practical enrollment, a cancellable practical booking,
and a three-day TDC batch. It does not change account credentials.

Steps:
    1. Create or locate an instructor schedule from 09:00 to 11:00.
    2. Try to create another schedule for the same instructor on the same date.
    3. Use an overlapping time, such as 10:00 to 12:00.

Expected result:
    - The second schedule is rejected.
    - The error identifies the instructor conflict.
    - No overlapping schedule is saved.

Adjacent-time check:
    - 09:00 to 11:00 and 11:00 to 13:00 should be allowed because they do not overlap.

16. TROUBLESHOOTING
-------------------
If the new lesson or batch fields cause an unknown-column error, run:

    docker compose exec app php artisan migrate
    docker compose restart app

If test credentials do not work in a newly seeded database, inspect the
seeder-defined password and update the credentials used for the demo.

Never use production credentials for this demo. These accounts are for local
or staging verification only.
